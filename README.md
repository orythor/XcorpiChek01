- Stalker Telegram
- Stalker YouTube

- Stalker Twitter/X
- Stalker Spotify
- Cek IP Detail
- Cek Security Website
- Screenshot Web
- Screenrecord Web

---

## Cara Install

```bash
pkg install git -y
git clone https://github.com/orythor/XcorpiChek01
cd XcorpiChek01
bash install.sh
```

## Cara Jalankan

```bash
bash xcorpichek01.sh
```

Atau setelah install (restart terminal dulu):
```bash
xcorpi
```

---

## Dependensi
Otomatis terinstall saat `install.sh`:
- `curl` `jq` `python3` `dnsutils` `openssl-tool`
- `pip: requests pillow`
- `playwright` (opsional, untuk screenshot/screenrecord)
